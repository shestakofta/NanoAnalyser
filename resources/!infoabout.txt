NPA — NanoParticle Analyzer
Анализ наночастиц на изображениях просвечивающей электронной микроскопии

Версия 4.1.ml

Назначение
Программа предназначена для автоматической обработки ПЭМ-снимков порошков и агломератов наночастиц металлов. Она находит на снимке вещество, выделяет крупные (модифицированные) частицы и тела неправильной формы, размечает первичные частицы в агломератах кругами, определяет их размеры, рассчитывает массы и долю массы модифицированных частиц по каждому снимку и по серии в целом.

Основные возможности
• Чтение снимков TIFF (в том числе с масштабом из метаданных Olympus/SIS), JPEG, PNG, BMP; определение масштаба по масштабной линейке.
• Вычитание неравномерного фона, удаление из контура участков подложки.
• Классификация крупных тел: модифицированные частицы, скопления, тела неправильной формы (НФ), агломераты.
• Разметка первичных частиц кругами, подобранная по ручной разметке экспертов.
• Расчёт масс: плоская оценка и оценка с учётом частиц, скрытых в глубине агломерата.
• Статистика распределений по размерам, графики, отчёты Microsoft Excel.
• Ручная правка разметки, измерения на снимке, пакетная обработка больших серий.
• Сбор набора размеченных снимков для машинного обучения.

Использованные методы
• Оценка числа первичных частиц по площади проекции агломерата: Köylü Ü.Ö. и др., Combustion and Flame, 1995.
• Маркерный водораздел с отбором по глубине долины: Beucher S., Meyer F., 1993; Najman L., Schmitt M., 1996.
• Разделение перекрывающихся выпуклых объектов: Zafari S. и др., arXiv:1906.01049.
