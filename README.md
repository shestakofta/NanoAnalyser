NPA автоматически обрабатывает ПЭМ-снимки порошков и агломератов наночастиц металлов. Программа находит на снимке вещество, выделяет крупные (модифицированные) частицы и тела неправильной формы, размечает первичные частицы в агломератах кругами, определяет их размеры, рассчитывает массы и **долю массы модифицированных частиц** — по каждому снимку и по серии в целом.

## Возможности

- **Чтение снимков** TIFF (в том числе с масштабом из метаданных Olympus/SIS), JPEG, PNG, BMP. Масштаб — из метаданных, по масштабной линейке на снимке или вручную в нм/пиксель.
- **Подготовка снимка:** вычитание неравномерного фона, удаление из контура тёмных участков подложки.
- **Классификация крупных тел:** модифицированные частицы, скопления, тела неправильной формы (НФ), агломераты.
- **Разметка первичных частиц кругами** в агломератах.
- **Расчёт масс:** плоская оценка и оценка с учётом частиц, скрытых в глубине агломерата (только для справки).
- **Статистика распределений по размерам:** среднее, медиана и мода диаметров; графики с сохранением в PNG, JPEG, PDF, SVG и CSV.
- **Отчёты Microsoft Excel:** краткий («Итог» и «Сводка») и полный (все частицы каждого снимка и параметры обработки).
- **Ручная правка разметки:** смена класса щелчком, удаление и добавление частиц и областей (круг, круг по трём точкам, контур, ломаная, сплайн), отмена до трёх последних изменений.
- **Измерения на снимке:** расстояние между точками и между параллельными линиями, диаметр круга, диаметр и масса частицы под курсором.
- **Пакетная обработка** больших серий на нескольких ядрах — в окне программы или из командной строки без окна.
- **Разметка для машинного обучения:** проверенную разметку снимка можно одной кнопкой добавить в набор данных и перенести набор на другой компьютер одним архивом.

### Что выделяется на снимке

| Класс | Что это | Как считается масса |
|---|---|---|
| Модифицированные частицы | крупные (больше отсечки, устанавливаемой пользователем) плотные округлые частицы | сплошной эллипсоид ближайшей формы |
| Агломераты | рыхлые цепочки мелких первичных частиц, размеченных кругами | сумма шаров видимых частиц; дополнительно — оценка с учётом глубины |
| НФ | плотные тела неправильной формы | эллипсоид из плотно упакованных шаров, прибавляется к агломератам |

**Доля модифицированной массы** = масса модифицированных / (модифицированные + агломераты). Плотность материала можно сменить после обработки — массы пересчитываются сразу.

## Запуск

Распакуйте архив целиком.

- **Windows:** запустите `NanoAnalyzer.exe` из папки `NanoAnalyzer`.
- **macOS:** перетащите **NPA ML.app** в «Программы» и откройте. Приложение не заверено Apple, поэтому при первом запуске откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**. Если кнопки нет или появляется сообщение «Приложение повреждено», выполните в Терминале:
  ```
  xattr -dr com.apple.quarantine "/Applications/NPA ML.app"
  ```
- **Linux:** `tar -xzf NanoAnalyzer-Linux.tar.gz`, затем `./NanoAnalyzer/NanoAnalyzer`. Нужна графическая среда (X11 или Wayland с XWayland).

Первый запуск может занять 10–20 секунд. Переносите программу на другие компьютеры архивом, а не копированием папки.

**Из исходников** (Python 3.10–3.12):

```
python -m pip install -r requirements.txt
python app.py
```

**Пакетный режим без окна:**

```
NanoAnalyzer.exe --batch ПАПКА_РЕЗУЛЬТАТОВ снимок1.tif снимок2.tif …
```

Программа сохранит в папку краткий и полный отчёты Excel, картинки разметки и журнал `batch_log.txt`. Настройки берутся из файла `nano_settings.json` рядом с программой (создаётся кнопкой «Сохранить настройки»), иначе — по умолчанию.

## Порядок работы

1. **«Выбрать файлы»** — один или несколько снимков.
2. Выберите материал (или плотность), при необходимости задайте масштаб и подвигайте ползунки «Отсечка контраста» и «Шумоподавление». Кнопка «Проверить на выбранном снимке» за 1–2 с показывает контур вещества.
3. **«Начать обработку»** — снимки обрабатываются параллельно.
4. Проверьте результаты на вкладках «Снимок», «Сводка», «Графики» и при необходимости поправьте разметку в разделе «Редактировать».
5. Сохраните картинки разметки, графики и отчёты Excel в разделе «Сохранение».

Подробное руководство — назначение каждого параметра, редактирование, измерения, разметка для ML, описание алгоритма и его проверки — в файле [resources/README.md](resources/README.md).

## Использованные методы

- Оценка числа первичных частиц по площади проекции агломерата: Köylü Ü.Ö. и др., *Combustion and Flame*, 1995.
- Маркерный водораздел с отбором по глубине долины: Beucher S., Meyer F., 1993; Najman L., Schmitt M., 1996.
- Разделение перекрывающихся выпуклых объектов: Zafari S. и др., 2020, [doi:10.1016/j.jvcir.2020.102962](https://doi.org/10.1016/j.jvcir.2020.102962).
- Разметка первичных частиц кругами (метод v8) и классификация крупных тел — собственные методы, подобранные по ручной разметке снимков.

> Результаты автоматической обработки носят оценочный характер и должны проверяться пользователем.
